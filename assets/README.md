# Demo assets

`orbital.obj` is an original parametric torus and sphere generated for this
project by `tools/generate_demo.py` (Python standard library). It has positions,
UVs, normals and triangle faces; no imported mesh or texture data is used.
The generator and generated model use the repository's MIT license.
Run `python tools/generate_demo.py` from any directory to reproduce the asset.

The default amber/teal checker is generated in `Texture::checker()`, also MIT.
